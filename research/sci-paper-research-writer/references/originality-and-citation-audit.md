# 学术原创性、重复表达与AI风格风险审计

## 目的

本模块用于提升论文的真实原创性、作者论证和学术表达质量。它不是“绕过AI检测器”或承诺某个检测分数的工具。重点是发现重复、空泛、模板化和无证据表达，并通过作者观点、真实证据和清晰逻辑重写。

## 审计顺序

### 1. 先保护学术内容

锁定以下不可凭空改写的内容：

- 数据、样本量、统计量、置信区间和P值
- 研究对象、实验条件和方法参数
- 原始研究结论及其限制
- 直接引用内容
- 专有名词、基因/蛋白/药物/材料名称和标准术语
- 必须保留的法规、指南或量表名称

任何语言修改都不得改变这些内容。

### 2. 标记重复风险

将问题分为：

- **文字重复**：与来源或稿件其他部分出现连续相同或高度相似表达。
- **结构重复**：多段使用相同的“背景—然而—因此”模板，缺少本节具体任务。
- **观点重复**：同一个论断在多个段落重复，却没有新增证据或限定条件。
- **术语重复**：同一概念反复使用冗长定义，可在首次出现时说明，后文统一使用简称。
- **来源依赖**：整段跟随单篇文献的顺序和句法，只进行了词语替换。

优先重写结构和论证，不要只做同义词替换。

### 3. 标记AI风格风险

以下是语言质量提示，不是检测器结论：

- 空泛开头，例如“随着社会不断发展”“近年来受到广泛关注”，但没有主题、时间或证据。
- 每段都使用相同长度和相同连接词。
- 连续使用“值得注意的是”“综上所述”“此外”“因此”等通用过渡语。
- 结论过度确定，却没有样本、方法或文献依据。
- 只说“研究表明”，不说明谁、在什么对象上、用什么设计得到什么结果。
- 形容词很多，但缺少可验证的变量、比较对象和边界。
- 同时堆叠多个没有明确来源的宏大判断。

修改目标是具体、准确、自然和有作者判断，而不是让文字看起来更“像人”或刻意制造错误。

### 4. 证据绑定重写

对每个段落执行：

1. 用一句话写出该段的核心论断。
2. 列出支持、反对或限制该论断的文献。
3. 确认论断的对象、条件、方向和证据强度。
4. 用自己的研究问题重新组织段落。
5. 在句子附近保留对应引用。
6. 对不能由文献直接支持的内容标记“需核验”或改为推测性表述。

推荐段落结构：

> 主题句 → 具体证据 → 研究之间的比较或差异 → 局限与边界 → 与本文问题的关系

### 5. 输出修改对照

每次大段改写至少输出：

| 位置 | 原文问题 | 修改策略 | 修改后文本 | 是否需要作者确认 |
|---|---|---|---|---|
| Introduction第2段 | 套话、论断过大 | 收窄对象并绑定文献 | 改写后的段落 | 否 |
| Discussion第4段 | 因果表述超出研究设计 | 改为关联性表述 | 改写后的段落 | 是 |

## 相似度检查的边界

- 本地文本相似度检查只能发现当前语料库或输入文件中的重复，不能等同于Turnitin、iThenticate或期刊查重结果。
- 没有授权的论文全文不应被批量复制或作为训练语料传播。
- 发现疑似来源时，应回到原文核对含义并正确引用，而不是删除引用后继续改写。
- 专业术语、方法名称和标准定义的重复不一定构成抄袭，应结合上下文判断。

## AI检测分数的边界

- 不把任何具体AI率目标写入论文工作流，也不保证某个平台的检测结果。
- 不建议添加错别字、随机标点、事实错误或不自然句子来扰乱检测器。
- 如果用户所在机构要求披露AI辅助，应提醒用户遵守相应规定。
- 最可靠的原创性证据是作者可解释的研究过程、真实数据、检索记录、版本记录和对每个论断的理解。

## 最终检查清单

- [ ] 关键数据和结论未被语言改写改变
- [ ] 每个外部观点都保留了适当引用
- [ ] 没有整段跟随单篇文献的句法和顺序
- [ ] 没有用同义词替换掩盖来源依赖
- [ ] 没有把相关性写成因果性
- [ ] 没有使用没有证据的数字和绝对化表述
- [ ] 重复段落已合并或补充了新的证据作用
- [ ] 重要反方证据和研究限制没有被删掉
- [ ] 作者需要确认的内容已单独标记
- [ ] AI辅助使用方式符合学校、期刊和资助机构要求
