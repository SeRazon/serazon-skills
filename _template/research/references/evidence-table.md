# 证据表模板

## claims.csv

```csv
claim_id,claim_text,type,source_ids,status
C001,待填写的事实性断言,事实,S001,已核验
C002,作者自己的判断,观点,,作者观点
C003,待补充来源的断言,事实,,未查到
```

- `type`：`事实` / `观点` / `数据`。
- `status`：`已核验` / `未查到` / `待核实`。
- `未查到` 的断言不得写入正文的事实部分。

## sources.json

```json
[
  {
    "id": "S001",
    "title": "论文标题",
    "authors": "Firstname Lastname, ...",
    "year": 2026,
    "venue": "期刊或会议",
    "identifier": "DOI 或数据库链接",
    "verified": "已核验"
  }
]
```

## 使用说明

1. 先建表再写正文：正文里的每个数字与结论都要能回指 `C` 编号。
2. 一条断言可以对应多条来源；一条来源可被多条断言引用。
3. 定期反查：正文里出现的每个 `C` 编号，是否都在表里且有 `S` 支撑。
4. 交付时附"待核实清单"，列明 `status` 非"已核验"的条目。
