# 动态规划

## 设计四步

1. **定状态**：用哪几个维度能唯一描述子问题（位置、容量、是否选、上一个是谁）。
2. **写转移**：当前状态由哪些更小状态推来；注意方向（正推/倒推）。
3. **定初值**：空集、长度为 0、容量为 0 的边界。
4. **定答案**：最大/最小/计数，注意"恰好"与"至多"的区别。

## 背包

| 类型 | 转移 | 循环顺序 |
|---|---|---|
| 01 背包 | `f[j] = max(f[j], f[j-w] + v)` | 容量**倒序** |
| 完全背包 | 同上 | 容量**正序** |
| 多重背包 | 二进制拆分 / 单调队列 | 拆分后按 01 |
| 分组背包 | 每组至多一个 | 组内倒序 |
| 树上背包 | 合并子树，`O(n²)` | 先递归再合并 |

初始化语义：

```text
求"至多/最大"：f 全 0
求"恰好装满"：f[0] = 0，其余 -INF（求最小则 +INF）
计数：f[0] = 1，其余 0
```

## 区间 DP

`f[l][r]` 表示区间最优，按**区间长度**从小到大枚举：

```text
for (len = 2; len <= n; ++len)
  for (l = 1; l + len - 1 <= n; ++l) {
    r = l + len - 1;
    for (k = l; k < r; ++k) f[l][r] = min(f[l][r], f[l][k] + f[k+1][r] + cost(l, r));
  }
```

典型：石子合并、括号匹配、回文划分。环形问题破环成链（复制一遍）。

## 树形 DP

- 选/不选：`f[u][0/1]`，`f[u][1] += f[v][0]`，`f[u][0] += max(f[v][0], f[v][1])`。
- 树上背包：`f[u][j]` 表示 u 子树选 j 个，合并时枚举分配，复杂度 O(n²)。
- 换根 DP：先求子树答案，再二次 DFS 把父亲贡献传下去。

## 状压 DP

`f[mask]` 或 `f[mask][i]`；n ≤ 20 时可用。

- TSP：`f[mask][i]` 表示已访问 mask、当前在 i 的最短路。
- 棋盘放置：预处理合法行状态，只枚举相容的上一行。
- 子集枚举：`for (s = m; s; s = (s - 1) & m)`。

## 数位 DP

按位从高到低，状态一般 `(pos, 是否贴着上界, 前导零, 其他约束)`，用记忆化搜索写最稳：

```text
dfs(pos, tight, lead, state):
  if pos == len: return 1
  if (!tight && !lead && vis: return memo
  枚举当前位 d（0..limit）→ 递归
```

## 概率与期望

- 期望线性性：`E[X + Y] = E[X] + E[Y]`，可拆分求和，不必求联合分布。
- 期望 DP 通常**倒推**：`E[u] = 1 + Σ p(u→v) · E[v]`。
- 概率正推：`p[v] += p[u] · p(u→v)`。
- 有环时列方程高斯消元，或按拓扑序。

## 四类优化

| 优化 | 识别信号 | 做法 |
|---|---|---|
| 前缀和/前缀最值 | 转移是 `f[i] = min(f[j]) + c`，j 连续 | 维护前缀 min |
| 单调队列 | 窗口长度固定，取窗口最值 | 双端队列，队首过期弹出 |
| 斜率优化 | 转移含 `f[j] + a[i]·b[j]` 乘积项 | 维护凸包，二分或指针 |
| 决策单调 | 最优决策点随 i 单调 | 分治优化 / 四边形不等式 |

线性递推 + 大指数：矩阵快速幂，O(k³ log n)。

## 常见坑

1. `long long` 溢出（方案数、乘积）。
2. 多测不清空 DP 数组。
3. "恰好"与"至多"的初值写反。
4. 区间 DP 的枚举顺序写成 `l` 外层（必须先长度）。
5. 滚动数组后旧值残留。
6. 计数题忘记取模，或减法后为负（`(x - y + MOD) % MOD`）。
