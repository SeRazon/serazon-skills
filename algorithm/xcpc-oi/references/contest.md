# 赛场与调试

## 赛前

- 打印模板（或本地可检索版本），确认**编译命令**：`g++ -O2 -std=c++17 -Wall`。
- 检查环境：栈大小（`ulimit -s`）、是否支持 `pb_ds`、是否禁用 `bits/stdc++.h`。
- 队伍分工：读题（2 人交叉）、主写、对拍/数据；约定"卡题 20 分钟必须换人"。

## 读题清单（每次必过）

1. 数据范围 → 复杂度上限。
2. 多测？`T` 组还是单组？清空了吗？
3. 取模？模数是多少？减法会不会为负？
4. 输出格式：空格、换行、大小写、`Case #x:`。
5. 特殊限制：图不连通、允许重边自环、坐标范围、精度要求。
6. 样例之外的边界：n = 1、全相同、极值、空集。

## 时间分配

```text
0–10 min   通读全部题目，标注难度与类型
10–40 min  先做最有把握的 1–2 题（保底）
40–…       按通过率排序推进；卡住 20 分钟换题
最后 15 min 检查：多测清空、数组大小、long long、输出格式
```

- 跟榜有风险：通过人数突然上涨可能是水题，也可能是坑题。
- 构造题先写暴力验证小规模，再推广。

## 对拍

```bash
# gen.cpp 生成随机数据，brute.cpp 暴力，fast.cpp 正解
for i in $(seq 1 1000); do
  ./gen > in.txt
  ./brute < in.txt > out1.txt
  ./fast  < in.txt > out2.txt
  if ! diff -q out1.txt out2.txt > /dev/null; then echo "WA on case $i"; break; fi
done
```

要点：生成器覆盖**边界**（n=1、全相同、极值），而不只是随机。

## 卡常手段（按性价比）

1. 快读（`getchar_unlocked` / `fread` 缓冲）。
2. 避免 `vector` 反复分配，提前 `reserve` 或改用静态数组。
3. 递归改迭代；减少函数调用层级。
4. 取模次数减少（累加后再取模，注意溢出）。
5. 用 `int` 而非 `long long`（确认不溢出时）。
6. 位运算代替除法/取模（2 的幂）。

## 错误定位表

| 现象 | 常见原因 |
|---|---|
| WA | 边界未处理、多测未清空、溢出、取模负数、排序比较器不严格、浮点精度 |
| TLE | 复杂度估错、常数过大、`endl` 刷新、`unordered_map` 被卡、递归开销 |
| RE | 数组越界、栈溢出、除零、`vector` 空访问、迭代器失效 |
| MLE | 数组开太大（`int[1e7][1e7]`）、多测未释放 |
| PE | 行末空格、多余空行、大小写 |

## 赛后复盘

- 记录：卡在哪一步（建模/算法/实现/调试）、正确解法、复杂度差距。
- 把新模板补进个人模板库，并标注**适用条件与坑**，否则下次还是会错。
- 同一类题连续错三次，说明是知识缺口，回去补专题而不是继续刷。
