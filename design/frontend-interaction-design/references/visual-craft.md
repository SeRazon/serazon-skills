# 视觉工艺与设计令牌

## Skill 1 · 微对比色阶分层

- 丢掉黑粗边框与纯黑文字。背景层之间用 **1%–3% 明度差**拉开层次，靠氛围而不是线条分割。
- 卡片优先用"底色 + 极浅阴影"而非描边；必须描边时用 1px 低对比色。
- 输入框聚焦**不描边**，改为双环阴影：

```css
/* 静默态 */
box-shadow: inset 0 0 0 1px hsl(220 12% 88%);
/* 聚焦态：内环提亮 + 外环扩散 */
box-shadow: inset 0 0 0 1px hsl(220 90% 60% / .55),
            0 0 0 3px hsl(220 90% 60% / .18);
```

## Skill 2 · 暗色模式字重减细

人眼有光晕效应，黑底白字看起来会粗一档。切暗色时字重自动减 40（如 600 → 560）。

- 可变字体：`font-variation-settings: "wght" 560`；不支持时降一档（600 → 500）。
- 同时把白色文字降到 92%–96% 不透明度，避免刺眼。
- 暗色下阴影几乎不可见，改用 1px 微亮描边或提高表面明度来分层。

## Skill 3 · 水墨晕染式流式打字

不是逐字硬蹦，而是每个字带模糊渐显：

- 单字：`filter: blur(6px)` → `blur(0)`，时长 **120ms**。
- 相邻字错开 **30ms** 依次进入，视觉上连成波浪。
- 行内图标下移 **0.125em**（1/8 字高），与文字视觉中线对齐。
- `prefers-reduced-motion` 下退化为直接显示。

## Skill 4 · 等宽数字与网格展开

- 数字变动区域：`font-variant-numeric: tabular-nums`，并给容器设最小宽度，防左右抖动。
- 内容展开不用 JS 量高度：

```css
.panel { display: grid; grid-template-rows: 0fr; transition: grid-template-rows 200ms ease; }
.panel[open] { grid-template-rows: 1fr; }
.panel > div { overflow: hidden; }
```

- 正文 `text-wrap: pretty`，避免末行只剩一个孤字；标题可配 `text-wrap: balance`。

## Skill 5 · 动效分性格

| 场景 | 阻尼 | 参数 | 观感 |
|---|---|---|---|
| 拖拽吸附 | 过阻尼（0% 超调） | `spring(1200, 80)` | 松手即咬死，零回弹 |
| 点赞反馈 | 欠阻尼 | `spring(380, 18)` | Q 弹、有余韵 |
| 复制对勾 | — | 2.5s 后自动隐身 | 不占地方 |

时长三档：120ms（微反馈）/ 200ms（常规过渡）/ 320ms（大面积位移）。缓动默认 `cubic-bezier(.2,.8,.2,1)`。

## 设计令牌（缺设计稿时的默认值）

```text
间距：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（基准 4）
字号：12 / 14 / 16 / 20 / 24 / 32 / 40；行高 1.4–1.6；正文 16
字重：400 / 500 / 560 / 600（暗色统一 -40）
圆角：4 / 8 / 12 / 16 / 999；同心公式：外圆角 = 内圆角 + 内边距
阴影：sm 0 1px 2px / md 0 4px 12px / lg 0 12px 32px（透明度 ≤ 8%）
描边：1px，hairline 用 inset 阴影；暗色下用 1px 亮色 8%–12%
断点：640 / 768 / 1024 / 1280 / 1536
层级：内容 0 / 悬浮 100 / 下拉 300 / 抽屉 500 / 模态 700 / 全局提示 900
```

使用原则：**令牌先于样式**。同一个值出现第三次就抽成变量，禁止散落魔法数字。
