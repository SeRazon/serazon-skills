# 触控热区与手感

视觉上克制是为了好看，物理上给足余量是对大拇指的基本尊重。成年人大拇指按在玻璃上的实际接触面约 **44–48px**；在 400% 画布上抠出的 16px 图标，落到手上就是一场射击游戏。

## Skill 1 · 热区尺寸铁律

- 图标视觉保持 16px 没问题，但代码里必须外扩透明 padding，把点击热区撑到 **40×40 起**。
- 空间再挤，**底线 28px**，且相邻热区不重叠。
- 实操双层防呆：设计侧把 16px 图标放进 **40×40 Frame** 导出；开发侧再补一层 padding 兜底。
- 列表行高 ≥ 56px；行内多个操作时，每个操作独占 ≥ 40×40。

## Skill 2 · 同义合并，焊死死区

- 头像与昵称跳同一个个人页时，中间 8px 间距是"死亡缝隙"——随手一戳毫无反应。
- **只要目的地相同，必须打包成一整块连续热区**，把真空带焊死。
- 实现：把两者放进同一个 `<a>` 或同一可点击容器，内部元素 `pointer-events: none`（保留必要的独立交互除外）。

## Skill 3 · 手势隔离缓冲带

- 顶部 tab 栏、可横滑卡片边缘，热区旁留 **约 20dp** 的手势隔离带。
- 否则用户想点按钮，手指带一点滑动惯性，整页被横滑切走。
- 横向轮播内部有按钮时，给按钮区域设置 `touch-action: manipulation` 并阻止冒泡。

## Skill 4 · Taptic 震动反馈

手指挡住视线时看不到按下状态，用户会怀疑"点没点中"，于是连戳。

- 手指触碰玻璃的瞬间给一次物理回弹：**轻**（选择/切换）、**中**（确认/发送）、**重**（警告/失败）。
- 时长几毫秒到 20ms 量级，强度与锐度按平台 API 调整；仅移动原生可用的能力，Web 端用视觉/动效替代。
- 不要给滚动、悬停加震动；同一动作不重复震。

## Skill 5 · 单手可达与安全区

- 主操作放在屏幕下 1/3；右下角为拇指优势区，破坏性操作避开。
- 底部固定操作必须让开手势条与刘海：`padding-bottom: max(12px, env(safe-area-inset-bottom))`。
- 顶部内容避开状态栏与挖孔：`padding-top: env(safe-area-inset-top)`。
- 横屏时重新评估热区位置，不要把关键按钮压在拇指够不到的角落。

## 触控与鼠标的差异

- `hover` 不能作为唯一发现手段：移动端没有悬停，操作入口必须常显或长按可达。
- 点击态要"按下即反馈"（缩放 0.98 或底色变化），不要等请求返回才给反应。
- 防抖与节流只用于高频事件（滚动、输入），不要给点击加延迟。
