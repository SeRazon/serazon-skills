# 无障碍与交付走查

## 对比度

- 正文文本 ≥ **4.5:1**；大字（≥ 24px 或 ≥ 18.66px 粗体）≥ **3:1**。
- 非文本元素（图标、边框、图表色块）≥ **3:1**。
- 暗色模式同样按此标准，不因"黑底"放宽；白色文字建议 92%–96% 不透明度。
- 不要仅用颜色传达状态：错误同时给图标与文案。

## 焦点与键盘

- **焦点可见**：禁止 `outline: none` 无替代；用双环或 2px 外描边，与背景对比 ≥ 3:1。
- 全流程可键盘完成：Tab 顺序与视觉一致，Enter/Space 触发，Esc 关闭弹层。
- 弹层做焦点陷阱，关闭后焦点归还触发元素；页面首个可聚焦元素提供"跳到主内容"链接。
- 自定义组件补齐角色与状态：`role`、`aria-expanded`、`aria-selected`、`aria-checked`。

## ARIA 要点

| 场景 | 写法 |
|---|---|
| 模态 | `role="dialog"` `aria-modal="true"` `aria-labelledby` 指向标题 |
| 高危确认 | `role="alertdialog"`，默认焦点落在安全选项 |
| 轻提示 | `aria-live="polite"` |
| 错误提示 | `aria-live="assertive"` + 字段 `aria-describedby` |
| 图标按钮 | `aria-label`，装饰性图标 `aria-hidden="true"` |

## 动效与偏好

- `prefers-reduced-motion: reduce`：位移、缩放、模糊全部退化为 ≤ 120ms 的淡入淡出。
- `prefers-color-scheme`：跟随系统，且允许手动覆盖并记住选择。
- `prefers-contrast: more`：提高描边与文字对比，去掉半透明装饰。
- 自动播放的动效/视频提供暂停；闪烁频率低于 3Hz。

## 适配与文本

- 200% 缩放不破版、不出现横向滚动；固定高度容器改为 `min-height`。
- 文本扩 30%（德语/俄语场景）不截断、不遮挡，按钮宽度用 `min-width` 而非固定值。
- 长英文单词与 URL 用 `overflow-wrap: anywhere`，避免撑破卡片。

## 交付前走查（20 条）

**弹层**

1. 每一层弹窗都有明确关闭方式（Esc、关闭按钮、遮罩规则明确）。
2. 打开时锁定背景滚动，关闭后焦点回到触发元素。
3. 填表弹窗有草稿保存，点遮罩不会静默丢数据。
4. 高危操作使用 AlertDialog，遮罩不可点、Esc 禁用、按钮动宾明确。

**表单**

5. label 常显，必填标识统一。
6. 错误文案说明"错在哪 + 怎么改"，且不自动消失。
7. 提交按钮有 loading 与防重复提交；失败保留已填内容。
8. 只有 2 个选项的字段没有用下拉；超过 10 项的列表可搜索。

**移动端**

9. 所有可点元素热区 ≥ 40×40（底线 28），相邻热区不重叠。
10. 同目的地的相邻元素合并为连续热区。
11. 底部元素让开安全区，主操作在拇指可达区。
12. Bottom Sheet 三档高度取整（30/60/80%），有拖拽把手与关闭方式。

**视觉**

13. 层次靠明度差，不靠黑粗边框；描边为单层 inset。
14. 聚焦态不是描边，而是双环阴影且对比足够。
15. 数字变动区开启 `tabular-nums`，无左右抖动。
16. 圆角内外同心，缩放后不出现"断层"。
17. 动效时长落在 120/200/320ms，拖拽零回弹、点赞有余韵。

**无障碍**

18. 正文对比度 ≥ 4.5:1，大字 ≥ 3:1。
19. 键盘可完成主流程，焦点可见且顺序合理。
20. 开启减少动效后，页面仍可完整使用。
