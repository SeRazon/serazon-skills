# 文字 PV 制作检查清单

## 1. 素材确认
- [ ] 音频文件路径、时长、采样信息。
- [ ] 歌词时间轴文件（每行：序号 / 歌词 / 开始 / 结束）。
- [ ] 用户确认歌词文本为权威版本（转写稿需校对）。

## 2. 视觉方向
- [ ] 风格：墨判文书 / 故障艺术 / 极简 / 其他。
- [ ] 比例：16:9 横版（1920×1080）或 9:16 竖版。
- [ ] 主字体：思源宋体 / 方正清刻本 / 其他宋体； annotation 字体：楷体。
- [ ] 主色：纸色、墨色、朱砂红、金棕。

## 3. 分段版式（不可整首一样）
| 段落 | 版式 | 核心动效 |
|---|---|---|
| 序 | 左对齐 + 红竖线 | 左侧滑入 |
| 怒 | 居中巨字 | scale  slam + 红背闪 |
| 间奏 | 网格清单 | 逐条砸入 |
| 冥 | 竖排碑文 | 右→左列显影 |
| 判 | 朱红边框 + 印章 | 定格 + 斩线 |

## 4. 渲染参数
- FPS: 30
- 分辨率: 按选定比例
- 母版 CRF: 20–24
- 分享版 CRF: 26
- 音频: AAC 192k

## 5. 校验
- [ ] 静帧检查每段版式。
- [ ] 检查长句是否裁切（heavy/verdict 段）。
- [ ] 抽查首尾帧音频同步。
- [ ] 检查文件大小是否适合分享。
